# Tool-selection forward packs

Tiny stdlib-only directories for later independent forward runs. Hand one
directory to an executor as a working tree. Do not treat a green unittest as
model `pass@k`. Do not encode expected answers here.

| Pack | Concrete need |
| --- | --- |
| `codegraph-callers` | Cross-file callers of `assemble` when CodeGraph is valid |
| `direct-read` | Known file `notes.txt`; direct read |
| `rtk-pytest` | Supported pytest summary with a real failure |
| `missing-tool-fallback` | Optional tools absent; baseline search |
| `semble-unknown` | Bounded keywords first, then unknown-implementation discovery |
